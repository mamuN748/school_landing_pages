কোনো স্মৃতিচারণ পোস্ট নেই

শিক্ষার্থীরা স্মৃতি শেয়ার করলে স্বয়ংক্রিয়ভাবে এখানে তালিকাভুক্ত হবে।

Google Firebase Firestore ক্লাউড কানেকশন

অফলাইন (লোকাল মোড)

ক্লাউড কানেক্ট সক্রিয় থাকলে যে কোনো মোবাইল বা কম্পিউটার থেকে দেওয়া ভিজিটর নাম, শিক্ষক ও স্মৃতিচারণ রিয়েল-টাইমে অন্য সকল ডিভাইসে স্বয়ংক্রিয়ভাবে সিঙ্ক হবে।

ডাটাবেজ টাইপ: Google Cloud Firestore (NoSQL)
প্রোজেক্ট আইডি: অপেক্ষমাণ
লাইভ সিঙ্ক স্ট্যাটাস: অফলাইন মোড সক্রিয়
সর্বশেষ সিঙ্ক সময়: এখনও হয়নি
⚙️ Firebase প্রজেক্ট কনফিগারেশন সেট করুন
ফ্রি Firebase Console থেকে নেওয়া Config কোডটি নিচের বক্সে পেস্ট করুন:
📖 মাত্র ২ মিনিটে সম্পূর্ণ ফ্রি Google Firebase সেটআপের নিয়ম:
  1. ধাপ ১ (প্রজেক্ট তৈরি): ব্রাউজারে console.firebase.google.com এ প্রবেশ করে আপনার জিমেইল দিয়ে লগইন করুন এবং "Create a project" (অথবা "Add project") বাটনে ক্লিক করে একটি নাম দিন (যেমন: ghoshgaon-school)।
  2. ধাপ ২ (Firestore চালু): বাম পাশের মেনু থেকে "Build" > "Firestore Database"-এ ক্লিক করে "Create database" চাপুন। রুলস অপশনে "Start in test mode" নির্বাচন করে Done চাপুন।
  3. ধাপ ৩ (কনফিগ কপি): হোমপেজ বা Project Settings (⚙️ গিয়ার আইকন)-এ গিয়ে Web আইকন (</>) সিলেক্ট করে অ্যাপ রেজিস্টার করুন। সেখানে প্রদর্শিত firebaseConfig = { ... } ব্র্যাকেটের অংশটুকু কপি করে ওপরের বক্সে পেস্ট করে "সংরক্ষণ ও ক্লাউড চালু করুন" বাটনে ক্লিক করুন!
